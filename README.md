# Framework para Avaliação de Completude e Alinhamento de Instrumentos de Planejamento Urbano

Este repositório reúne os **artefatos, modelos e resultados** da tese de doutorado de Matheus Moreira Cruz (UFF), que propõe um **framework inovador** para apoiar gestores públicos na análise da **completude** e do **alinhamento** entre diferentes documentos de planejamento urbano.

## 📌 Sobre o Projeto
As cidades produzem diversos instrumentos de planejamento (Plano Diretor, PPA, LDO, LOA, Plano de Metas etc.). Na prática, esses documentos muitas vezes são fragmentados, redundantes ou desalinhados.  
O framework proposto neste repositório oferece uma forma **sistemática e reproduzível** de avaliar esses documentos, apoiando a tomada de decisão baseada em evidências.

## 🏛️ Estudo de Caso: São Paulo
O framework foi instanciado para a cidade de **São Paulo**, permitindo:
- Avaliar a **completude** de cada documento (o que está presente e o que falta).
- Medir o **alinhamento** entre planos de diferentes horizontes temporais.
- Identificar **lacunas, redundâncias e inconsistências** de forma objetiva.

## 📂 Conteúdo do Repositório
- **Artefatos do Framework**  
  Modelos conceituais, constructos de relacionamento (alinhamento, execução e previsão) e classificações de documentos.  

- **Instanciação em São Paulo**  
  Estruturas documentais, matrizes de comparação, análises de completude e alinhamento entre Agenda 2030, Plano de Metas, PPA, LDO e LOA.  

- **Prototipagem**  
  Telas ilustrativas demonstrando como o framework pode ser aplicado em um sistema computacional.  

## 🚀 Contribuição
Este repositório serve como base para pesquisadores, gestores públicos e desenvolvedores interessados em:
- Analisar a qualidade de documentos de planejamento urbano.
- Replicar ou adaptar o framework para outros municípios.
- Explorar aplicações práticas de **interoperabilidade, dados urbanos e automação** com apoio de modelos de linguagem.
